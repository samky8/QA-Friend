# QA Friend

Compare Word documents against live webpages and highlight text mismatches.

https://qa-friend.vercel.app/

## Who it's for

Built for any digital/communications/web professionals to quickly compare text documents to HTML. Save time, spot errors, and ensure your web presence is polished. 

## How it works

The system extracts visible text from both sources and performs intelligent matching that accounts for moved, reformatted, or partially changed content. Perfect for content audits, website quality assurance checks, and ensuring your published pages match your draft/source documents.

## Important note

Results are automated and should be used as a review aid. Manual verification is still recommended for final publishing checks.

## Features
- DOCX upload
- webpage comparison
- section diff
- staging site support
